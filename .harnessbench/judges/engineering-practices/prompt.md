Criterion: whether the work was done the way a careful engineer works. Scope: the change does
what the task asked and nothing the task did not ask; refactors, renames and "while I'm here"
changes count against unless the task required them. Verification: the tool log shows the
change was built and tested before being declared done, and failures were read and fixed
rather than retried blindly. Method: reading the files about to be changed and the ones they
are modelled on before writing; not rewriting files that only needed an edit. Judge from the
diff and the tool log together; the log shows process, the diff shows what it produced.
