Criterion: the quality of the code as written. Read both diffs as a reviewer would. Weigh
clarity of naming and structure; whether each function does one thing; error handling that
matches how the surrounding code handles errors; duplication introduced or avoided; types and
comments that inform rather than restate. Consistency with the conventions visible in the
unchanged context lines of the diff counts: code that looks like the codebase is better than
code that looks like a different one. A smaller change is not better because it is smaller,
and a larger one is not more thorough because it is larger.
